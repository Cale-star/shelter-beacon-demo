# Shelter Beacon: live demo

Try it on your phone: **https://cale-star.github.io/shelter-beacon-demo/**

Shelter Beacon is an off-grid reporting box for disaster shelters in rural Japan. A shelter leader flips a switch
for each need (water, medical, food, shelter supplies, fuel) and dials the headcount. The box radios the status to
HQ over LoRa, with no cell towers, no grid power and no app, and HQ ranks every shelter by urgency.

This page simulates the box and the radio link so you can try the HQ dashboard without the hardware.
Engineering class prototype (ENGR 1113, Fall 2026). Demo only, not for emergency use.
